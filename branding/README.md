# Origo Branding

- **Name**: Origo (English) / 元启 (Chinese).
- **Meaning**: *Origo* is Latin for "origin, beginning" — the origin of a new, AI-native computing model; 元启 combines 元 (origin/principal/meta) and 启 (to begin/enlighten).
- **Voice**: minimal, calm, capable; technology that recedes into the background.

## Usage
- Use the full name "Origo" for the project and OS; the agent is the "Origo agent".
- Do not imply the project endorses derivative products without permission.
- Trademarks will be held by the project and later transferred to a stable legal entity/foundation.

Logo, colors, boot splash, wallpapers: **to be contributed for v0.1** (minimal mark welcome; no skeuomorphic decoration). Proposals should be simple, legible at small sizes, and open-licensed.
